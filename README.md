# market-data-platform

## Project 0 — Foundations (Architecture Only)

This repository currently contains the architectural foundations of a modular, data-driven financial system.

**In scope (Project 0):**
- Repository structure, architectural layers, standards, and documentation
- Interfaces/contracts for future modules (ingestion, storage, features, backtesting, ML, decision support, and optional execution)
- Configuration, logging, and testing philosophy

**Out of scope (Project 0):**
- No trading strategies implemented
- No machine learning models implemented
- No backtesting engine implemented
- No execution / live trading logic implemented
